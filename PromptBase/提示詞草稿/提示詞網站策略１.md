# Prompt 網站產品規格 V2

## 1. 產品定位

### 1.1 產品名稱

暫定：

> **AI Prompt Toolbox**
>
> AI 提示詞工具箱

核心概念不是單純「收藏 Prompt」，而是：

> **讓使用者快速找到、修改、測試、複製並重複使用高品質 Prompt。**

---

## 2. 第一階段產品策略

### 2.1 初期採用 A 方案

第一階段採用：

> **A. 一般使用者／個人／小團隊私藏庫**

而不是一開始就建立公開投稿、會員、付費解鎖的平台。

### MVP 第一階段

```text
管理員
   ↓
新增 / 修改 Prompt
   ↓
Google Sheets
   ↓
GAS API
   ↓
Prompt 網站
   ↓
搜尋 / 篩選 / 填變數 / 複製
```

### 第二階段

再逐步增加：

```text
使用者帳號
投稿
審核
收藏

排行榜
分享
```

### 第三階段

再考慮：

```text
Prompt Marketplace
會員
付費 Prompt
Workflow
AI Prompt Generator
團隊共享
```

# 3. 核心產品理念

> **Prompt 不是文章，而是一個可以直接使用的工具。**

每一則 Prompt 不應只是標題加上一大段文字，而應該包含：

```text
Prompt
├── 做什麼？
├── 什麼情境使用？
├── 適用模型
├── 輸入變數
├── Prompt 本體
├── 範例輸出
├── 使用注意事項
├── 品質評分
└── 一鍵複製
```

# 9. Prompt 變數系統

這是 V2 的核心功能之一。

例如：

```text
請以 {{角色}} 的身份，
針對 {{主題}} 撰寫一篇 {{字數}} 字的文章。

語氣要求：
{{語氣}}
```

系統自動解析並產生表單：

```text
角色： [____________]

主題： [____________]

字數： [____________]

語氣：
[專業 ▼]
```

使用者輸入後：

```text
[預覽完整 Prompt]

[複製 Prompt]
```

# 33. V2 最終核心定位

> ### 「不是收藏最多 Prompt 的網站，而是讓你最快找到並真正用起來的 AI Prompt 工具箱。」

核心 KPI 不應只是「有多少 Prompt」，而應該是：

### **Prompt → 使用成功率**

追蹤：

```text
搜尋
 ↓
查看
 ↓
填變數
 ↓
複製
 ↓
收藏
 ↓
再次使用
```

這比單純追求 Prompt 數量更能判斷網站是否真正有價值。

## 35. V2 開發建議

不要直接開始大量寫程式。

先把以下四個核心資料結構定死：

```text
prompts
logs
versions
categories
```

接著再定義：

```text
Google Sheets 欄位
        ↓
GAS API
        ↓
Frontend State
        ↓
UI Components
```

如此可以降低後續因資料結構變動而反覆修改前後端的成本。
