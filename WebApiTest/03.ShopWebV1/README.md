# 賈斯汀 AI 課程商業應用網站

彩墨藍・迪淺色風格的 AI 課程選課站：桌遊風格翻牌卡、即時選課車、管理員課程維護，
資料來源為 Google 試算表（menu / orders），透過 Google Apps Script Web App 串接。

## 檔案結構

| 檔案 | 說明 |
| --- | --- |
| `index.html` | 頁面骨架（僅結構，含背景動畫層的內聯 SVG） |
| `style.css` | 全部樣式；配色集中於最上方的 `:root` 設計代幣 |
| `main.js` | 全部邏輯；**API 設定集中於檔案最上方的「① API 設定區」** |
| `Code.gs` | 後端 Google Apps Script（貼進 Apps Script 編輯器即可部署） |
| `tests.html` / `tests.js` | 單元＋整合測試（瀏覽器直接開啟即執行，51 項） |
| `shop.csv` | 課程原始資料，可直接匯入 Google 試算表的 `menu` 工作表 |
| `docs/01_BDD.md` | 行為驅動開發文件（Gherkin 驗收情境） |
| `docs/02_TDD.md` | 測試驅動開發文件（測試案例與開發節奏） |
| `docs/03_SDD.md` | 軟體設計文件（架構、資料模型、API 契約、視覺規格） |
| `docs/04_框架評估.md` | React / Vue / Angular 適用性評估與演進路線 |

## 三步驟啟用

1. **建立試算表**：`menu` 工作表標題列為
   `id, name, category, description, price, imageUrl, status`（可直接匯入 `shop.csv`）；
   `orders` 工作表標題列為 `orderId, customerName, items, totalPrice, timestamp`。
2. **部署 Apps Script**：把 `Code.gs` 全部內容貼進 Apps Script 編輯器，
   確認最上方的 `SPREADSHEET_ID` 正確，先手動執行一次 `setupSheets()` 建立標題列，
   再「部署 → 新增部署 → 網頁應用程式」（執行身分：我；存取權：所有人），複製 `/exec` 網址。
   後端支援 `doGet(?action=read)` 與 `doPost`（action 為 `order` / `add` / `delete`），
   回應格式一律為 `{ status:'success'|'error', message, data }`。
3. **填入網址**：打開 `main.js`，將最上方的

   ```js
   const API_URL = ''; // ← ★ 請在此貼上你的 GAS Web App 網址
   ```

   改成你的 `/exec` 網址，存檔後重新整理即可。

> 未填 `API_URL` 時，網站會自動進入 **離線展示模式**：使用內建 10 門示範課程，
> 下單／新增／刪除皆以模擬回應完整跑一次流程，方便先驗收畫面。

## 名額規則

- 每堂課開課上限 **50 人**（`COURSE_CAPACITY`）。
- `menu.status` 欄位保存剩餘名額，目前採**純數字**（例：`50`、`48`）；
  後端 `Code.gs` 的 `SEAT_STATUS_FORMAT = 'number'` 也以數字寫回。
  前端仍相容舊寫法（「剩餘 15 個名額」「熱銷中 (剩 5 名)」）。
- 剩餘 **低於 25** 時，卡片背面顯示紅色脈動警語「僅剩 NN 名，欲購從速」；為 0 時停用加入按鈕。
- **下單扣除 → 退貨回補**：下單成功後後端回傳 `updatedSeats`、退貨回傳 `restoredSeats`，
  前端直接依後端數值更新畫面；回補後名額不會超過 50。

## 退貨（名額回補）

1. 切換為管理員模式 → 面板下方的「訂單退貨」區塊。
2. 訂單編號可從下拉清單挑選（自動讀取 orders 工作表，顯示姓名與金額）或手動輸入。
3. 送出後後端會讀取該訂單的 `items` 明細，把名額加回 `menu`，
   並把該筆訂單的 `status` 標記為「已退貨」（此欄不存在時會自動建立），同一筆訂單無法重複退貨。

## 改版後行為沒變？先確認版本號

前端版本顯示在**頁尾**（例：`前端版本 v1.4.1`），F12 主控台啟動訊息也會印出同一組版本號。
若版本號比 `main.js` 最上方的 `APP_VERSION` 舊，代表瀏覽器用了**快取的舊檔**：

- 按 **Ctrl + F5**（Mac 為 Cmd + Shift + R）強制重載
- `index.html` 已在 `style.css?v=` 與 `main.js?v=` 帶上版本參數，改版時同步更新這三處數字即可讓所有使用者自動取得新檔

除錯小工具：在主控台輸入 `JustinAI.resetDiscounts()` 可清除所有已鎖定的翻牌折扣並重新抽籤。

## 翻牌特價（隨機折扣）

- 卡片**正面只顯示定價與「翻牌有驚喜」**，折數與折後價一律翻到背面才揭曉。
- 每張課程卡**第一次翻牌**時會隨機抽出 **75 ~ 99 折**並鎖定，之後翻幾次都是同一個折數。
- 折數保存在瀏覽器 `localStorage`，重新整理仍沿用；隱私模式下自動退回「僅本次瀏覽有效」。
- 折後價會同步套用到卡片正反面、選課車與訂單；後端以「試算表定價 × 折數」覆算金額，
  前端傳來的價格僅供對帳，不會被直接採信。

## 操作提示

- 滑鼠移到課程卡即翻牌，再點卡片下方的「加入課程」即可加入選課車。
  觸控裝置為兩段式：第一次點擊翻牌、翻牌後再點下方按鈕加入。
- 右上角「切換為管理員模式」→ 頂部滑出新增課程表單（含**開課名額**下拉選單，
  可選 6 ~ 50 人，預設 50 人滿編），卡片右上角出現紅色刪除鈕。
- 退貨下拉選單只列出**尚未退貨**的訂單，已標記「已退貨」者自動排除。
- 手機版選課車收於右下角浮動按鈕，點擊由底部滑出。
