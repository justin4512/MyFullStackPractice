# 冰島追極光之旅 — Apple Design 調整版

本資料夾為獨立完整副本；上層原專案維持不變。

## 預覽

在本資料夾啟動靜態網站伺服器，例如 `python3 -m http.server 8000`，再開啟 http://localhost:8000 。
地圖、字型、圖示與即時住宿需要網路連線。

## 調整

- 可中斷的抽屜 spring、速度採樣、慣性停靠與漸進邊界阻力。
- 日期文字與常用觸控區域放大。
- 桌機與手機均先呈現當日行程。
- 跟隨系統／淺色／深色，選擇持續保存。
- 收斂陰影與漸層，浮動工具採輕量玻璃材質；支援減少動態、降低透明度與高對比偏好。

## 驗證

`node --test tests/interaction.test.cjs` 執行六項行為測試。
瀏覽器已檢查 320、390、900、1440px 四種寬度、日期數量、主題重載保存、頁面溢出與抽屜開啟。觸控手感仍需在真實手機體驗。

## 行程調整（景點增減）

在「行程」頁的「當日站點」按 **調整景點**：

- 刪除、上下移動站點，修改每站停留分鐘；起點（前一晚住宿）與終點（今晚住宿）固定不動。
- **新增景點**：在輸入框打名稱，從已知地點挑選（含已刪除、未排入的地點）；清單沒有的，用地圖左上角搜尋，在結果視窗按「加入 Day N 行程」。
- 每次變動都即時重算：路段用 OSRM 實算，**冬季時間 = 理論 × 1.2**。新路段若經過冬季封閉的 Öxi（939）或 F 路，會自動改用原規劃的海岸繞行點。
- 按 **儲存到 NAS** 後頁面重新載入，總覽、每日行車波形圖、行前提醒、指南表格都用新的數字。「還原原始規劃」可把某一天恢復成 `data.js` 的版本。

存檔位置與運作：

| 項目 | 說明 |
|---|---|
| 存檔 | NAS 上的 `data/plan.json`（每次寫入前備份到 `data/backups/`，保留 30 份） |
| 服務 | `docker-compose.yml` 的 `api` 容器（`tools/plan_api.py`），nginx 把 `/api/plan` 轉給它 |
| 載入 | `js/plan.js` 先讀 `api/plan` 套用到 `data.js`，再載入 `app.js`；讀不到就用原始行程 |
| 衝突 | 兩台裝置同時改，後存的會收到「其他裝置剛更新過」，重新整理後再改 |
| 密碼 | 在 `docker-compose.yml` 同資料夾建立 `.env`，寫 `EDIT_TOKEN=你的密碼`；網頁第一次儲存時會詢問 |

本機預覽（含存檔 API）：

```bash
python3 tools/plan_api.py --port 8767 --static . --data data
```

測試：`node --test tests/plan.test.cjs tests/interaction.test.cjs`
