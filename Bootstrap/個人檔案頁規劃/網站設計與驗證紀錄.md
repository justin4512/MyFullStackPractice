# 網站設計與驗證紀錄

日期：2026-11-03。範圍：本機靜態網站開發，尚未部署。

## 設計依據

以使用者指定的 `dash.jpg` 儀表板為主：深藍側欄、淺藍灰面板、浮凸圓角控制元件、木紋主視覺，以及可核對的數據卡與長條圖。以 Bootstrap 既有斷點為參考，新增樣式統一放入 `css/myAll.css`，限定於 `.profile-site`。

ui-ux-pro-max 用於互動與視覺規格；design-taste-frontend 用於畫面檢視。後者抽出的 contact-sheet、quiet-instrument、type-only 方向並未取代使用者已接受的儀表板設計。其通用的無陰影、無漸層、少卡片原則與本案明確需求衝突，因此保留指定的浮凸材質與數據卡。照片由使用者後續補入，目前使用清楚標示的概念插圖。

全站採 Why 動機 → How 方法與責任 → What 問題與結果。數據必須帶單位與口徑；6,160 為每月等效人工處理量，不是節省工時。案例不捏造服務可用率、營運改善百分比或未測量的效益。

作品用 Flex 卡片，封面靜止、資訊遮罩滑入，對應使用者指定的照片滑動 CSS 參考。圖片及標題連至公開作品，另一個入口連至站內案例。Slider 手動控制，不自動輪播；停用 JavaScript 時仍能讀取全部故事。

## 驗證狀態

已通過的 Python 匯出整合測試共 4 項：

1. 目的地有無關 HTML 時，拒絕匯出且保留原檔。
2. 目的地有無關 robots.txt 或 sitemap.xml 時，在任何寫入前拒絕匯出。
3. 本機匯出包含 9 頁、可解析的站內資源及實際履歷下載。
4. 正式網址可用根目錄或路徑前綴，canonical 與 sitemap 正確產生，重複匯出一致。

重新產生後，9 頁皆以 HTTP 200 回應；靜態檢查確認每頁單一 H1、無重複 ID、站內資源與錨點存在、JSON-LD 可解析，以及另開視窗連結具 noopener。`js/profile.js` 通過 Node 語法檢查；CSS diff 無空白格式錯誤。這些檢查不取代瀏覽器互動驗證。

```sh
python3 -m unittest discover -s tests -p 'test_profile_build.py' -v
```

前一輪瀏覽器測試已涵蓋 Slider、鍵盤、手機選單、作品篩選、停用 JavaScript 與 reduced-motion，並留有 375、768、1440 像素截圖。畫面檢視發現封面高度受 HTML height 屬性影響，已改為 CSS height:auto；同時放大正文與小字，並將手機箭頭維持 44px。

另已修正：焦點位於故事連結時，方向鍵不會切換並隱藏該連結；匯出器先完成全部衝突檢查，再開始寫檔。前者已見過修正前的失敗測試，後者修正後的 Python 測試通過。

最後一輪 Chrome 權限請求未獲允許，因此**最新 CSS 與焦點修正尚未重新完成瀏覽器測試**；新增的真實觸控模擬、file:// 檢查與 design inspector 也未取得本輪通過結果。既有截圖只代表先前版本，不作為最新版完整通過的證據。不宣稱通過完整 WCAG、螢幕閱讀器或真實裝置驗證。

瀏覽器測試保留於 `tests/profile-site.test.mjs`，需在本機預覽運作且 Playwright／Chrome 可用時執行。`PLAYWRIGHT_MODULE` 可指定 Playwright 的模組位置，`PROFILE_CHROME` 可指定 Chrome 執行檔。
