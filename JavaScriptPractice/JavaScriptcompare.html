JavaScript 變數大比較

程式小白也能懂：let、const、var 到底差在哪裡？

先記住一句話就好：

在現代 JavaScript 中， 優先使用 const，需要改變值時才使用 let。

var 是 JavaScript 早期的變數宣告方式， 現代程式開發通常不建議再使用。

① 三種寫法先認識

var

傳統寫法

``` var name = "Justin";
```

可以重新指定值。

``` var name = "Justin"; name = "Tom";
```

⚠️ 作用域與提升行為比較容易造成問題。

let

可以改變的變數

``` let age = 20;
```

可以重新指定值。

``` let age = 20; age = 21;
```

✅ 現代 JavaScript 中，需要「會改變的值」時使用。

const

不可以重新指定

``` const country = "Taiwan";
```

建立後不能重新指定。

``` const country = "Taiwan"; // ❌ 錯誤 country = "Japan";
```

✅ 如果知道這個變數不需要改變，優先使用。

🧠 程式小白記憶法

可以把變數想成「盒子」：

📦 let → 盒子裡面的東西可以換。

🔒 const → 盒子貼上封條，不能重新指定。

📦 var → 老式盒子，規則比較寬鬆，容易出現意外。

最簡單的選擇：

不會改 → const

會改 → let

除非是在維護舊程式碼，否則 → 不要用 var
