🧠 Debug 決策摘要

Console→ Network→ Status→ Headers→ Payload→ Response
最快判斷法：
沒有 Request → 前端流程。
4xx → Request / Auth / 欄位格式。
5xx → 後端或上游服務。
200 但畫面壞 → 前端解析 / 資料結構。
